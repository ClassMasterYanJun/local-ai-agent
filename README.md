# Локальный ИИ для Windows

Полностью автономный пакет для запуска `Qwen2.5 7B Instruct (Q4_K_M)` на Windows 10/11 x64. Модель обслуживает портативный `llama.cpp`, расположенный в папке проекта. При подготовке и работе чата сеть не используется.

Ollama не нужна: пакет её не устанавливает, не запускает, не использует её хранилище моделей и не меняет переменные среды пользователя.

## Запуск для пользователя

Дважды щёлкните **`Install-LocalAI.vbs`**. Он открывает графический мастер без окна консоли. Мастер:

1. проверяет целостность GGUF по SHA-256;
2. проверяет свободное место и объём ОЗУ;
3. запускает `runtime\llama.cpp\llama-server.exe` вместе с моделью из этой папки;
4. проверяет ответ модели и открывает чат в браузере.

Повторно открыть чат можно командой:

```powershell
.\Start-Chat.ps1
```

## Управление сервером ИИ

Дважды щёлкните **`Manage-LocalAI.vbs`**. В системном трее Windows появится значок управления. Нажмите его левой кнопкой, чтобы открыть панель с кнопками; правая кнопка открывает быстрое меню.

- **Запустить ИИ** — загружает модель и запускает локальный сервер;
- **Остановить ИИ** — останавливает только `llama-server.exe` этого проекта и освобождает память;
- **Открыть чат** — запускает сервер при необходимости и открывает браузер;
- **Обновить статус** — показывает состояние модели.

Те же операции доступны из консоли:

```powershell
.\Control-LocalAI.ps1 -Action Start
.\Control-LocalAI.ps1 -Action Stop
.\Control-LocalAI.ps1 -Action Status
.\Control-LocalAI.ps1 -Action Chat
```

## Консольный режим

Для автоматизации используйте:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Console
```

Добавьте `-NoBrowser`, чтобы подготовить локальный сервер, но не открывать браузер.

## Содержимое автономного пакета

Перед публикацией релиза проверьте наличие всех файлов, включая DLL из архива llama.cpp:

```text
runtime/
  llama.cpp/
    llama-server.exe
    llama-server-impl.dll
    llama.dll
    ggml*.dll
    libomp.dll
    ...                             # остальные файлы официального CPU-архива llama.cpp
models/package/
  local-assistant.gguf              # Qwen2.5-7B-Instruct-Q4_K_M.gguf (4,36 ГиБ)
  model.json                        # идентификатор, размер и SHA-256 модели
```

Используется официальный Windows x64 CPU-выпуск llama.cpp `b11146`. CPU-вариант выбран намеренно: он работает на компьютерах без CUDA/Vulkan и не зависит от драйверов дискретной видеокарты.

Контрольная сумма модели указана в `models/package/model.json`:

```text
65b8fcd92af6b4fefa935c625d1ac27ea29dcb6ee14589c55a8f115ceaaa1423
```

Проверить её перед распространением:

```powershell
(Get-FileHash .\models\package\local-assistant.gguf -Algorithm SHA256).Hash.ToLowerInvariant()
```

Для распаковки и работы пакета требуется не менее 10 ГиБ свободного пространства на диске с проектом. Рекомендуется 8 ГиБ ОЗУ или больше; на CPU генерация может быть медленной.

## Локальные адреса

- Веб-чат: `http://127.0.0.1:8787/`
- OpenAI-совместимый API llama.cpp: `http://127.0.0.1:8080/v1/`

Сервер привязан только к `127.0.0.1`, поэтому не доступен из локальной сети. Для быстрой проверки API:

```powershell
Invoke-RestMethod http://127.0.0.1:8080/v1/models
```

## Публикация больших файлов

Обычный Git не подходит для многогигабайтных весов. Предпочтительные варианты:

1. **архив релиза** — рекомендуемый вариант: один ZIP/ISO с GGUF, `runtime\llama.cpp` и скриптами;
2. **Git LFS** — если у хостинга достаточно квоты и модель допускается к распространению;
3. внутреннее файловое хранилище — для закрытой поставки.

`.gitignore` исключает GGUF и каталог портативного runtime, чтобы они не попали в обычный коммит. При сборке релиза включите их физически в архив.

## Что означает «обучение» в проекте

`train-model.ps1` создаёт профиль системной инструкции для запросов к API. Он не выполняет дообучение весов и не изменяет GGUF. Для настоящего дообучения нужны отдельный контур (например, PyTorch/Transformers и LoRA), совместимые веса и подготовленный датасет.
